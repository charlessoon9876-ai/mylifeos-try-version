# MyLifeOS V0.1 Try Version

This is the first runnable prototype of MyLifeOS.

## Included
- Dashboard
- Daily Log
- Six Domains
- Daily Review
- Local browser storage

## Six Domains
- Health
- Wealth
- Career
- Family
- Growth
- Lifestyle

## How to try it
Open `index.html` in a browser.

This version intentionally keeps data local in the browser. No cloud database or AI API is connected yet.
